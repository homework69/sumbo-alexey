# САМБО — защищённая панель клуба (Vue 3)

Адаптивная панель управления учениками секции самбо: рейтинг, группы 18:00 / 19:00 / 20:00, фотографии, оценки и модальная форма добавления/редактирования. Доступ к панели требует входа тренера через Supabase Auth.

## 1. Установка

Нужен Node.js LTS. В папке проекта выполните:

```bash
npm install
npm run dev
```

## 2. Настройка Supabase и входа тренера

1. Создайте проект на https://supabase.com/.
2. В **Authentication → Users** нажмите **Add user** и создайте учётную запись тренера с email и паролем. Не добавляйте форму регистрации на сайт.
3. В **Authentication → Settings** отключите публичную регистрацию (**Allow new users to sign up**), чтобы посетители не могли самостоятельно создавать аккаунты.
4. В **SQL Editor** выполните весь `supabase/schema.sql`. Скрипт включает RLS, удаляет открытые политики из прежней версии и делает bucket фотографий приватным.
5. Скопируйте `.env.example` в `.env` и заполните адрес проекта и публичный anon/publishable key:

```env
VITE_SUPABASE_URL=https://ВАШ_ПРОЕКТ.supabase.co
VITE_SUPABASE_ANON_KEY=ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ
```

6. Перезапустите `npm run dev`. Войдите с email и паролем созданного тренера.

### Что защищено

- Без входа интерфейс управления и данные учеников недоступны.
- Таблица `students` разрешает чтение, добавление, изменение и удаление только роли `authenticated`.
- Фото находятся в приватном Supabase Storage bucket `student-photos`; клиент получает временные подписанные ссылки.
- В публичном клиенте используется только anon/publishable key. **Никогда не добавляйте `service_role` или secret key во фронтенд.**

> Важно: политики разрешают доступ всем вошедшим в проект пользователям. Поэтому обязательно отключите публичную регистрацию и создавайте аккаунты тренеров только вручную в панели Supabase. Если ранее проект уже содержал открытые данные, выполнение SQL закроет их для анонимных посетителей, но старые фотографии, загруженные в публичный bucket, могут быть доступны по ранее выданным публичным URL до проверки/очистки.

## 3. Рейтинг

Итог из 100 очков: посещаемость (до 50), поведение (до 25), успеваемость (до 25).

## 4. Сборка и публикация

```bash
npm run build
npm run preview
```

На Vercel/Netlify добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в переменные окружения. После изменения переменных запустите новый deploy.
